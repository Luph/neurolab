\section{Yeniden üretme}\label{README-yeniden-uxfcretme}}

\begin{gbkod}
pip install -r kod/requirements.txt
kod/hepsini_uret.sh                                     # bütün hesaplar → veri/ (girdi/'deki ham verilerden)
kod/hepsini_uret.sh --cevrimdisi --cikti /tmp/gb_veri   # ağsız sınama: başka klasöre üret, veri/ ile karşılaştır
latex/derle.sh                                          # şekiller, LaTeX gövdeleri ve bütün PDF'ler → pdf/
\end{gbkod}

\begin{itemize}
\tightlist
\item
  \textbf{Süre.} Hesaplar ≈20--30 dakika sürer; çoğu çekim modelinde (19 PPML spesifikasyonu, 1.000 çekilişli genel denge) ve STA ağı genel dengesinde. PDF'ler ≈4 dakika.
\item
  \textbf{Sınama sonucu (18.10.2026).} Çevrimdışı kipte Faz 0--3'ün bütün betikleri (31 adım) paketteki girdilerle çalıştı. \kod{veri/\allowbreak{}} klasöründeki 77 dosya (Faz 3'ün grup yüzdelikleri ve 1/98 askısı çıktıları dahil) ve düzyazı belgesi \kod{nace\_\allowbreak{}kartlar\_\allowbreak{}10-\allowbreak{}12.\allowbreak{}md} bayt bayt aynı üretildi (\kod{kod/\allowbreak{}dogrula.\allowbreak{}py}). Faz 3 hesapları ≈1,5 dakika sürüyor.
\item
  \textbf{Tek tek çalıştırma.} Betikler \kod{kod/\allowbreak{}} içinden argümansız çalışır. Varsayılan girdi \kod{girdi/\allowbreak{}}, çıktı \kod{veri/\allowbreak{}}. Örnek: \kod{python3 f2e\_\allowbreak{}s4\_\allowbreak{}aktif.\allowbreak{}py}. Sıra \kod{hepsini\_\allowbreak{}uret.\allowbreak{}sh} içinde.
\item
  \textbf{PDF için gerekenler.} pandoc ≥ 3.1, TeX Live 2023 (LuaLaTeX, latexmk, KOMA-Script, polyglossia), TeX Gyre ve DejaVu yazı tipleri. Ubuntu'da: \kod{apt-\allowbreak{}get install pandoc texlive-\allowbreak{}luatex texlive-\allowbreak{}latex-\allowbreak{}extra texlive-\allowbreak{}fonts-\allowbreak{}extra texlive-\allowbreak{}lang-\allowbreak{}european latexmk fonts-\allowbreak{}dejavu}.
\end{itemize}

\textbf{Ham verinin kaynakları.} Betikler Eurostat (SDMX ve Comext), EU Vocabularies (ShowVoc), GİB, TÜİK, TCMB EVDS3, UN Comtrade, WITS, CEPII, SGK, Ticaret Bakanlığı, AB Yayın Ofisi, ECB, DESTA ve BM'den herkese açık dosyaları kullanır; kimlik doğrulama gerekmez.

\begin{itemize}
\tightlist
\item
  Bu dosyalar \kod{girdi/\allowbreak{}} klasöründedir.
\item
  Bir dosya silinirse betik onu kaynağından yeniden indirir.
\item
  Pakete sığmayan üç kaynak (BACI tam dosyaları, CEPII Gravity zip'i, TÜİK iş kayıtlarının ham CSV'si) için betiklerin okuduğu özetler konuldu. Ayrıntı: \belgebag{README}{}{\kod{girdi/\allowbreak{}README.\allowbreak{}md}}.
\end{itemize}
